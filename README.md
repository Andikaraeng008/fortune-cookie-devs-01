One original fortune-cookie line for a software developer, written for make.fun's "Fortune Cookie Wisdom for Developers" bounty.

> The bug you cannot reproduce is the bug that knows your name.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
